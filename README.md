# PrimeNest Marketplace Demo

Frontend-only real estate marketplace client preview for the Nigerian market.

## Live demo

https://primenest-marketplace-demo-demoski.vercel.app

## Scope

- Property marketplace homepage
- Search and filters
- Property detail views
- Seller dashboard demo
- Add-property flow using browser storage
- Admin moderation demo
- Featured / boosted / premium promotion demo
- No backend, authentication, database, or real payments

## Deployment

This project is a static site and can be deployed directly to Vercel.
